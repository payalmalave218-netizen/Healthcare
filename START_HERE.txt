===============================================
TROUBLESHOOTING
===============================================

If the app doesn't start:

1. Run: python test_setup.py
   This will tell you what's wrong

2. Check if Flask is installed:
   pip install Flask

3. Check if port 5000 is available
   If not, change port in app.py (line 259)

4. Make sure you're in the correct folder
   The folder should contain: app.py, database/, templates/, static/

5. See TROUBLESHOOTING.md for detailed help


===============================================
WHAT TO EXPECT
